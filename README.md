# arduino-cat-jukebox

Музыкальная штука на ардуинке. Двигаешь джойстик, с компа играет трек, а на экранчике 1602 танцует кошкомальчик в такт музыке.

Ардуина тут только читает джойстик и рисует на экране, музыку играет питоновский скрипт. Он заранее находит биты в треке (librosa) и на каждый бит шлет ардуине команду по сериалу, кошкомальчик делает следующее движение.

Под каждый трек свой танец, зависит от темпа:
- до 90 bpm качается из стороны в сторону
- 90-130 прыгает
- больше 130 прыгает и машет руками

Если название трека не влезает на экран, оно бежит строкой. Снизу пишется темп и какой танец сейчас.

## Управление

- влево - Face "Лиза"
- вправо - Френдзона "Бойчик"
- вверх - Roxette "Listen to Your Heart"
- вниз - громкость (100/75/50/25/0 по кругу)
- нажать на стик - стоп

Треки в репу не кладу, свои mp3 надо закинуть в папку music с именами left.mp3, right.mp3, up.mp3. Названия на экране меняются в player.py в SLOTS (только латиница, экран не умеет кириллицу).

## Что нужно

- Arduino Uno (у меня китайский клон на ch340)
- LCD 1602 без i2c
- джойстик
- потенциометр 10к для контраста
- резистор 220 на подсветку
- макетка и провода

## Подключение

Экран:
```
VSS -> GND
VDD -> 5V
V0  -> средняя нога потенциометра (крайние на 5V и GND)
RS  -> 12
RW  -> GND
E   -> 11
D4  -> 5
D5  -> 4
D6  -> 3
D7  -> 2
A   -> 5V через 220 Ом
K   -> GND
```
D0-D3 не подключаются.

Джойстик: VRx -> A0, VRy -> A1, SW -> 7, питание на 5V и GND.

## Запуск

1. Залить cat_jukebox/cat_jukebox.ino через Arduino IDE. Монитор порта потом закрыть, а то он занимает порт и скрипт не подключится
2. `pip install -r requirements.txt`
3. `python player.py` (порт ищется сам, если нет то `python player.py --port COM5`)

В первый раз скрипт пару секунд анализирует каждый трек, потом берет из кэша.

Если кошкомальчик прыгает раньше или позже бита, крутить LATENCY_S в player.py. Если на экране пусто, крутить потенциометр контраста (у меня так было).

## Как ардуина общается с компом

Простые строки по сериалу на 9600.

С ардуины: L, R, U - выбор трека, D - громкость, S - стоп.

С компа:
- `N:название` - начался трек
- `T:128` - темп
- `B` - бит
- `V:75` - громкость
- `X` - музыка кончилась
