# 🐱🎵 Cat Jukebox

Музыкальная шкатулка на Arduino Uno: наклоняешь джойстик — играет мелодия,
а пиксельный **кошкомальчик** на экране LCD 1602 прыгает в такт каждой ноте.

## Возможности

- 3 мелодии, переключение наклоном джойстика
- Анимация кошкомальчика на пользовательских символах LCD (спрайты 5×8)
- **Неблокирующее** проигрывание через `millis()` — музыка, анимация и опрос джойстика работают одновременно, без `delay()`
- Мелодии хранятся как массивы нот — новая песня добавляется парой строк

## Управление

| Джойстик | Песня |
|---|---|
| ← влево | FACE — «Лиза» |
| → вправо | Френдзона — «Бойчик» |
| ↑ вверх | Roxette — «Listen to Your Heart» |
| нажатие | стоп |

Кошкомальчик прыгает на каждую ноту, а рядом с ним летает ♪.

> Ноты этих песен в репозиторий не входят — они защищены авторским правом.
> Подбери мелодии сам и вставь в `songs.h` (см. раздел ниже). Пока слоты не
> заполнены, играют мелодии общественного достояния: «Ода к радости»,
> «Коробейники», «Twinkle Twinkle Little Star».

## Компоненты

- Arduino Uno (подойдёт клон на CH340)
- LCD 1602 (параллельный интерфейс, без I2C)
- Модуль джойстика (KY-023)
- Пассивная пищалка
- Потенциометр 10 кОм (контраст экрана)
- Резистор 220 Ом (подсветка), макетная плата, провода

## Схема подключения

**LCD 1602**

| LCD | Arduino |
|---|---|
| VSS | GND |
| VDD | 5V |
| V0 | средний вывод потенциометра (крайние — 5V и GND) |
| RS | D12 |
| RW | GND |
| E | D11 |
| D4 | D5 |
| D5 | D4 |
| D6 | D3 |
| D7 | D2 |
| A | 5V через 220 Ом |
| K | GND |

**Джойстик:** GND → GND, +5V → 5V, VRx → A0, VRy → A1, SW → D7
**Пищалка:** + → D8, − → GND

## Запуск

1. Открой `cat_jukebox/cat_jukebox.ino` в Arduino IDE
2. Плата: *Arduino Uno*, выбери порт
3. Загрузи скетч

Если на экране нет символов — покрути потенциометр контраста.

## Структура

```
cat_jukebox/
├── cat_jukebox.ino   # логика: джойстик, проигрыватель, отрисовка
├── songs.h           # мелодии
├── sprites.h         # спрайты кошкомальчика и нотки
└── pitches.h         # частоты нот
```

## Как добавить свою мелодию

В `songs.h` создай массив нот и добавь его в `SONGS`:

```cpp
const Note MY_SONG[] = { {NOTE_C4,2}, {NOTE_E4,2}, {NOTE_G4,4} };

const Song SONGS[] = {
  // ...
  SONG("MY SONG", MY_SONG, 200),
};
```

Длительность ноты = `units × unitMs` миллисекунд.
