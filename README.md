# 🐱🎵 Cat Jukebox

Наклоняешь джойстик — с компьютера играет трек, а пиксельный **кошкомальчик**
на экране LCD 1602 прыгает точно в бит.

## Как это работает

```
 джойстик ──► Arduino ──(USB Serial: L/R/U/D/S)──► player.py ──► колонки 🔊
                 ▲                                   │
                 └──(N:название, T:темп, B:бит, V:громкость)──┘
                 LCD 1602: кошкомальчик танцует на каждый B
```

- `player.py` заранее находит биты каждого трека с помощью **librosa** (beat tracking) и кэширует их
- Во время игры сверяет позицию воспроизведения с битами и шлёт на Arduino команду прыжка
- По темпу трека кошкомальчик выбирает танец
- Длинное название трека бежит строкой, громкость показывается шкалой
- Arduino опрашивает джойстик, рисует спрайты на LCD и ничего не блокирует (`millis()` вместо `delay()`)

## Танцы

| Темп | Танец | Что делает кошкомальчик |
|---|---|---|
| < 90 BPM | SWAY | качается влево-вправо |
| 90–130 BPM | JUMP | прыгает |
| > 130 BPM | PARTY | руки вверх → прыжок → руки вверх → стойка |

Внизу экрана видно темп и текущий танец, например `128BPM JUMP`.

## Управление

| Джойстик | Трек |
|---|---|
| ← влево | FACE — «Лиза» |
| → вправо | Френдзона — «Бойчик» |
| ↑ вверх | Roxette — «Listen to Your Heart» |
| ↓ вниз | громкость 100 → 75 → 50 → 25 → 0 % (по кругу) |
| нажатие | стоп |

Музыка в репозиторий не входит — положи свои mp3 в папку `music/`:

```
music/
├── left.mp3    # влево
├── right.mp3   # вправо
└── up.mp3      # вверх
```

Названия на экране и имена файлов меняются в словаре `SLOTS` в `player.py`.

## Компоненты

- Arduino Uno (подойдёт клон на CH340)
- LCD 1602 (параллельный интерфейс, без I2C)
- Модуль джойстика (KY-023)
- Потенциометр 10 кОм (контраст экрана)
- Резистор 220 Ом (подсветка), макетная плата, провода
- Компьютер с колонками / наушниками

## Схема подключения

**LCD 1602**

| LCD | Arduino |
|---|---|
| VSS | GND |
| VDD | 5V |
| V0 | средний вывод потенциометра (крайние — 5V и GND) |
| RS | D12 |
| RW | GND |
| E | D11 |
| D4 | D5 |
| D5 | D4 |
| D6 | D3 |
| D7 | D2 |
| A | 5V через 220 Ом |
| K | GND |

**Джойстик:** GND → GND, +5V → 5V, VRx → A0, VRy → A1, SW → D7

## Запуск

1. Залей `cat_jukebox/cat_jukebox.ino` на Arduino Uno через Arduino IDE и **закрой монитор порта** (он занимает COM-порт)
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Положи треки в `music/` и запусти:
   ```bash
   python player.py              # порт ищется сам
   python player.py --port COM5  # или явно
   ```
   При первом запуске биты считаются несколько секунд на трек, дальше берутся из кэша.

Если кошкомальчик прыгает чуть раньше или позже бита — подстрой `LATENCY_S` в `player.py`.
Если на экране нет символов — покрути потенциометр контраста.
